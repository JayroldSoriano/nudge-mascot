Nudge is installed. One more step.

The extension draws Nudge in your browser. A small helper on your computer tells it when Claude Code needs you. Set that up once and you're done.

Checking for the helper…
  1. 1

    Run this once in your terminal

    npx nudge-mascot setup

    It adds the Claude Code hooks to ~/.claude/settings.json (with a backup) and starts a tiny relay on 127.0.0.1 that keeps running at login. Needs Node 18 or newer. This page updates on its own when the relay is running.

  2. 2

    Paste the connection code

    Setup ends by printing a code (run npx nudge-mascot status to see it again). Paste it here or in the toolbar popup's Connect.

    The relay listens on 127.0.0.1, which every program and user on this computer can reach. The code, stored only in ~/.claude-nudge/secret (readable by you alone) and in this browser, is what lets Nudge read Claude's messages and answer for you, and keeps everything else out.

  3. 3

    Restart Claude Code

    Quit any running Claude Code session and start it again so it picks up the new hooks.

  4. 4

    Send a test nudge

    npx nudge-mascot test

    Then switch to any website tab. Nudge waves in the corner. Settings live in the toolbar popup.
